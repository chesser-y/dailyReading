### 2611.25656 · A²-VLA — *A²-VLA: Adapting Vision-Language-Action Policies to New Tools through Agentic Affordance Discovery*

**方向与更新。** VLA、跨工具泛化、agentic affordance discovery、real-to-sim；v1 于北京时间 **11-19 15:38:47** 首次提交。[原文](https://arxiv.org/abs/2611.25656) · [v1 HTML](https://arxiv.org/html/2611.25656v1) · [alphaXiv zh（本次不可访问）](https://www.alphaxiv.org/zh/abs/2611.25656)

**核心贡献。** 给定少量源工具遥操作示范，系统先重建工具、物体、相机和机器人布局，再由 agent 识别任务相关功能区域（例如钩端、切削边或支撑面）及其位置、方向等几何属性。在模拟中把源工具轨迹 retarget 到其他工具，读取接触和任务结果，迭代修正 affordance-extraction skill，并将成功 skill 保存到可复用库。最终把 12 维功能区域特征编码为单个 affordance token，加入图像、语言和机器人状态上下文，条件化 π₀.₅ 的 flow-matching action expert。

**证据与状态。** 三个模拟工具替换任务的共享 retarget 评估中，A²-VLA 平均成功率 86.1%，Raw VLM 为 37.8%。Dobot Nova 2 双臂、三台 RealSense D405 的未见工具真机评估中，A²-VLA 平均成功率 35.3%，π₀.₅ 为 4.7%；源工具上为 46.0% 对 22.0%。从第 0 到第 6 次模拟修正，Cut Sand、Reset Plate、Pnp Ring 的成功率分别提升 23.8、18.3、30.0 个百分点。代码、权重和数据开放状态未核实。**阅读程度：** 已选读原文第3—5节、附录A—C，核对图2、表1—3和训练/推理细节；未核查代码。

## 重点解读

### A²-VLA：把“工具迁移”转成可验证的功能几何接口

**核心问题。** 同一任务可由不同外形工具完成，但工具身份、抓取姿态和末端轨迹都可能改变。若 VLA 只看图像和语言，训练集中没有出现过的新工具会暴露接触区域与方向的缺口；若只复制源轨迹，又无法处理工具长度、曲率和安装姿态变化。

**方法流程。** 源工具的校准图像、遥操作轨迹、相机参数与机器人模型 → agent 做 real-to-sim 场景重建；比较源工具示范，提出功能区域和几何属性 → 在模拟中执行跨工具轨迹 retarget，获得任务成功、接触和诊断反馈 → 修正区域、方向或提取 skill，并把可复用 skill 放入库 → 对未见工具提取统一 12 维特征。训练时该特征经 affordance encoder 成为单 token，与图像、语言、状态 token 一起输入 π₀.₅；action expert 输出 14 维动作 flow velocity，同时预测未来每一步 affordance trajectory。

**关键设计。** 12 维向量不是固定语义模板的关键点集合，而是任务级协议下的位置、轴方向外积和有符号任务方向；这样可表达“钩端近似水平”“切削面朝向材料”“支撑面法线与抬升方向”等接触条件。辅助 affordance 头把当前特征与动作块中的后续特征逐步配对，迫使动作预测保持功能几何一致；额外 10% counterfactual retargeting 数据训练策略跟随被扰动后的 affordance，而不是机械复现原轨迹。推理时，agent 可先在模拟中测试新工具，再把更新后的特征送入 VLA 重新规划动作块。

**实验结论与局限。** 86.1% 的模拟 retarget 结果说明，测试—修正 affordance 比一次性 VLM 预测更可靠；但真机未见工具平均 35.3% 仍低于 Human Oracle 的 47.3%，说明剩余瓶颈可能在感知、执行和 affordance-to-action 解码，而不只是表示发现。实验只覆盖三个工具任务、一个双臂平台和重建场景，不能直接外推到开放环境或多本体操作。

**思考与借鉴。** 作者实际验证的是 agentic affordance 发现、模拟修正和 π₀.₅ 条件化的组合；“几何 affordance token 可以纠正 latent action 的场景偏置”是本项目推断。最小实验建议是固定同一 action expert，在工具替换任务中比较图像/语言、SALA latent action、A²-VLA affordance token、二者组合四种输入，分别记录 retarget 成功率、动作块误差、affordance 预测误差和真机恢复次数。

## 研究联系与下一步

A²-VLA 的中间接口偏向“工具功能几何”，SALA 偏向“跨本体动作语义”，MARS 偏向“长时序中的技能选择”。三者可以组成一条可测试链路：affordance token 定义接触目标，latent action 表示跨本体动作意图，原子技能路由器负责在执行阶段选择控制粒度。下一步优先做同一插入或钩取任务的三路消融，避免把模拟 retarget、latent 可预测性和闭环成功率混成一个指标。
