### 2611.17110 · SALA — *SALA: Semantically Aligned Latent Actions Enable Dual-Axis Scaling of Embodied Foundation Models*

**方向与更新。** 跨本体 latent action、从人类视频学习、VLA；v1 于北京时间 **11-13 01:04:50** 首次提交，v2 于 **11-15 22:43:43** 修订。本期按 v1 HTML 的方法与实验核读，并记录 v2 为新版本变化。[原文与版本历史](https://arxiv.org/abs/2611.17110) · [v1 HTML](https://arxiv.org/html/2611.17110v1) · [alphaXiv zh（本次未取得正文）](https://www.alphaxiv.org/zh/abs/2611.17110) · [作者项目](https://sala-vla.github.io/)

**核心贡献。** 机器人与人类片段共享视觉编码器、SoftVQ 和视觉解码器；机器人片段另用动作解码器把 latent 锚定到可控动作。原子动作文本的相似度构成软邻域，训练时只把人类 latent 拉向语义相近的机器人 latent，避免场景外观主导表示。冻结 tokenizer 后，Qwen3-VL-4B 与 0.6B action expert 同时预测人类/机器人 latent token，机器人数据再做 flow matching。

**证据与可借鉴性。** 63-DoF 真机上，通用人类视频预训练增至 2,678 小时后，固定机器人数据的动作预测 L1 误差持续下降；任务级人类视频后训练从 10% 到 100% 时，四任务平均成功率由 53.75% 升到 72.5%。RoboTwin 2.0 的 Aloha-AgileX 消融中，完整 SALA clean/random 为 80.2/48.6%，去掉语义对齐为 75.5/36.8%。论文称代码为 “Code soon”，权重和数据开放状态未核实。**阅读程度：** 已选读原文第2、3、5节及附录实现细节，核对方法图2、实验图4和表5；未核查代码。

## 重点解读

### SALA：把跨本体迁移的瓶颈放到 latent action 的几何上

**核心问题。** 人类视频便宜且规模大，但人手和机器人手臂完成同一动作时轨迹、视角和场景不同；若 latent 只负责重建未来画面，它可能编码“桌面长什么样”，而非“正在抓取还是放置”。

**方法流程。** 对观测片段的起止帧做 inverse-dynamics 编码，SoftVQ 压成 8 个 token，再由视觉解码器重建未来特征；机器人片段额外由动作解码器重建 action chunk，因此机器人 latent 具备控制锚点。随后用原子动作文本相似度得到人类片段相对机器人片段的软邻域，以交叉熵匹配 latent 邻域，并对机器人 latent stop-gradient。冻结 tokenizer 给两类视频产生 latent 标签，action expert 对两类数据做 latent 分类，对机器人数据再做 flow matching。

**关键设计与实验结论。** 语言不是直接给出动作，而是定义“哪些跨本体片段应该接近”；stop-gradient 把对齐方向固定为“人类向机器人控制空间靠拢”。作者的扩展证据是动作 L1 误差随通用人类视频量下降、任务成功率随任务人类视频量上升，但后者只在四个任务和 63-DoF 平台报告。去掉 alignment 的随机场景降幅大于 clean 场景，支持“减少场景聚类”的解释。局限是原子动作描述仍需标注，且最大 2,678 小时的趋势尚未证明能无限外推。

**思考与借鉴。** 作者实际验证了语言对齐及双轴扩展；“统一多模态模型应显式学习动作语义邻域”是本项目推断。值得复现的最小对照是固定 action expert，仅替换 tokenizer 的 reconstruction-only、语义软邻域和语义软邻域但无 robot action decoder 三种训练，按场景变化、动作类别和跨本体分别评估 latent 可预测性。

### MARS：把长时序动作预测拆成“何时切换”和“如何控制”

**核心问题。** 通用 VLA 的同一动作头要覆盖搬运和插入，容易在精细接触阶段失稳；整任务 RL 又让奖励信号跨越很长的动作链。

**方法流程。** 图像、指令进入冻结 SmolVLA，中间 token 经 adapter 得到紧凑 RL Token；每个原子技能接收该状态、本体和 VLA 参考动作，用 TD3 优化局部操作。路由器读取历史状态窗口，同时把候选技能文字编码为查询，交叉注意力产生候选相关特征，再输出路由概率；阈值与连续确认决定何时切换，低层输出动作块。

**关键设计与实验结论。** 共享 RL Token 避免每个技能重复学习视觉—语言表示；时间记忆和技能语义分别在固定轨迹和闭环中贡献增益。真机结果显示从 12% 到 74% 的整任务成功率提升，但平台、相机、布局均固定，不能推断为广泛 sim-to-real 结论。论文也清楚区分了局部技能评估与闭环评估，这是报告动作预测能力时应保留的协议边界。

**思考与借鉴。** 作者验证了分阶段 RL 与动态路由的组合；把路由概率和切换轨迹反馈给统一动作模型、用于后训练或测试时适应，是本项目推断。可与 MR0 的 Rollback 配对：同一插入任务中分别记录路由错误和人工回退，比较仅路由、仅纠错与二者组合的成功率、切换次数、恢复时间。

## 研究联系与下一步

SALA 解决“动作表示怎样跨本体对齐”，MARS 解决“动作预测怎样在长时序中分工与切换”；前者偏预训练表示，后者偏后训练与部署。下一步建议先做一个小规模双臂插入实验：用 SALA 式语义 latent 作为共享动作 token，再让 MARS 路由器选择通用/插入专技，统一记录 latent 预测准确率、路由 Macro-F1、闭环成功率和恢复延迟。这样可以区分收益来自更好的表示、局部控制，还是路由本身。完整 cs.RO 公告逐条补抓与两篇 alphaXiv 中文概述仍是待补检索范围。
